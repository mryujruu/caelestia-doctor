# caelestia-doctor

أداة لتشخيص مشكلات **أنظمة Arch وما بُني عليها (مثل CachyOS)** و**Hyprland** و**واجهة [Caelestia](https://github.com/caelestia-dots)** وإصلاحها. تخبرك بما يجب فعله بعد كل مشكلة، وفي بعض الحالات الآمنة تصلح الملف بنفسها.

> أداة مجتمعية غير رسمية، وليست تابعة لمشروع Caelestia.
> النسخة الإنجليزية: [README.md](README.md)

## الأمان باختصار

| نوع الأمر | ماذا يفعل |
|---|---|
| `check` و`deep-check` و`logs` و`command-check` و`report` وكل أمر مع `--dry-run` | **للقراءة فقط.** لا يغيّر أي شيء. |
| `fix` و`undo` و`restore` و`backup restore` و`packages` و`install` | يغيّر شيئًا **بعد موافقتك فقط**، ويأخذ نسخة احتياطية من الملف قبل تعديله. |
| `fix --all` | يطبّق كل الإصلاحات المحلية الآمنة **دون سؤال**. استخدمه بعد قراءة نتيجة `fix --dry-run`. |

لا تحذف الأداة ملفاتك ولا حزمك، ولا تحدّث نظامك كله، ولا تنفّذ الأوامر التي تلصقها في `command-check`.

## التثبيت

```sh
sudo pacman -S --needed python-pipx
pipx install git+https://github.com/mryujruu/caelestia-doctor
pipx ensurepath          # ثم افتح طرفية جديدة
caelestia-doctor --version
```

للتحديث: `pipx upgrade caelestia-doctor`. تحتاج Python 3.11 أو أحدث.

## بداية سريعة

```sh
caelestia-doctor                # تشغيل كل الفحوصات مع الاقتراحات
caelestia-doctor fix --dry-run  # معاينة الإصلاحات دون تغيير
caelestia-doctor fix            # اختر الإصلاحات ثم أكّد
caelestia-doctor report         # تقرير جاهز للصقه في GitHub
```

## الأوامر

| الأمر | وظيفته |
|---|---|
| `check` (الافتراضي) | يشغّل كل الفحوصات ويعرض قائمة **What to do** تحت كل مشكلة. |
| `deep-check [--full]` | فحص أبطأ بـ `pacman -Qkk` يصنّف كل ملف تغيّر داخل الحزم. لا يحذّر إلا من **المحتوى المتغيّر خارج `/etc`** و**الملفات الناقصة**، ويذكرها بالاسم. أما تعديلاتك في `/etc` والوثائق والترجمات المحذوفة وفروق الوقت أو الصلاحيات فتُحسب دون اعتبارها مشكلة. الخيار `--full` يعرض كل ملف حسب نوعه. يعرض النتائج فقط. |
| `fix [--all] [--dry-run]` | يعرض الإصلاحات الآمنة، ويسأل أيها تطبّق، ثم يسأل مرة أخرى. `--dry-run` للمعاينة فقط. |
| `undo BACKUP` | يستعيد نسخة احتياطية أنشأها `fix`. يسأل أولًا ويحفظ الملف الحالي كنسخة أخرى. |
| `restore [--component hypr] [--dry-run]` | يقارن إعداداتك بالملفات الافتراضية الرسمية لـ Caelestia، ويعرض الناقص، ويسأل **عن كل ملف** قبل تنزيله. |
| `packages [--component hypr] [--dry-run]` | يراجع الحزم المذكورة في قائمة Caelestia ويعرض تثبيت كل حزمة ناقصة. حزم AUR وغير المدرجة تظهر منفصلة مع تحذير بقراءة PKGBUILD. |
| `backup list ARCHIVE` | يعرض الملفات المدعومة داخل نسختك الاحتياطية (tar) دون فك الضغط. |
| `backup restore ARCHIVE [--dry-run]` | يستعيد ملفات مختارة من النسخة، ويسأل عن كل ملف. تُتجاهل الروابط والمسارات غير المدعومة. |
| `logs [-o FILE]` | يقرأ آخر سجلات Hyprland وQuickshell دون رفعها. حفظ التقرير يطلب موافقتك. |
| `command-check --shell fish\|bash --command TEXT` (أو `--file FILE`) | يفحص **صياغة** أمر ملصوق بوضع Fish دون تنفيذ. يقترح `set` لعبارات Bash البسيطة `name=value`، وينبّه إذا غاب `less` بعد الأنبوب. |
| `install` | يعرض تثبيت `less` الاختياري بـ `pacman` بعد موافقتك. |
| `report [--format markdown\|json] [-o FILE]` | يطبع تقريرًا يستبدل مسار المنزل واسم المستخدم بـ `~` و`<user>`. |

خيار عام: `--no-color` (أو المتغير `NO_COLOR`).

## ماذا يفحص `check`

- **النظام:** التعرّف على أنظمة Arch (ومنها CachyOS)، والمساحة الحرة، وقفل pacman العالق، وقاعدة بيانات pacman، وملفات الحزم الناقصة، والخدمات الفاشلة.
- **الإصدارات:** `caelestia -v` وQuickshell وHyprland وحزم pacman المتعلقة.
- **`shell.json`:** صحة JSON (مع رقم السطر والعمود)، والمفاتيح المكررة، والمسارات التي لا توجد. يكشف خطأ الحروف الكبيرة والصغيرة مثل `wallpapers` بدل `Wallpapers`.
- **Hyprland:** هل الإعداد Lua أم `.conf` (بحسب إصدارك)، وأخطاء `hyprctl configerrors`، وصياغة Lua إن وُجد `luac`، وأكواد لغة الكيبورد (`ar` غير صالح و`ara` صالح) مع أقرب اقتراح.
- **Fish:** صياغة `~/.config/fish/config.fish` و`user-config.fish` بـ `fish -n` دون تشغيل الملف.
- **ملفات الحالة:** `scheme.json` و`wallpaper/path.txt`.

التفاصيل والحدود: [docs/checks.md](docs/checks.md).

## الإصلاحات الآمنة (`fix`)

لا توجد إلا إصلاحات لها إجابة واحدة واضحة:

- ملف **`shell.json` الفارغ** يصبح `{}`.
- قيمة في **`paths.*`** لا يخالفها إلا حالة الأحرف تُستبدل بالمسار الموجود فعلًا.

كل تعديل يُحفظ أولًا في `<name>.backup-<date>`، ويُكتب بشكل ذرّي، ويُرفض إن تغيّر الملف بعد الفحص. أما بقية المشكلات (JSON غير صالح، أكواد لغة الكيبورد، الحزم الناقصة، ملفات الحالة) فتُشرح ولا تُعدَّل، لأن الجواب الصحيح يعتمد عليك.

## التنزيلات وحد الطلبات في GitHub

يقرأ `restore` و`packages` فرع `main` الحالي من `caelestia-dots/caelestia`. في كل تشغيل لـ `restore` يثبّت الأداة commit واحدًا، ويتحقق من كل ملف بالهاش، ويرفض المسارات التي تخرج من مجلد المنزل، ولا يكتب فوق ملف موجود.

يحدّ GitHub الطلبات المجهولة. إن ظهر `HTTP 403` فانتظر قليلًا أو استخدم توكن قراءة فقط:

```sh
GITHUB_TOKEN=$(gh auth token) caelestia-doctor restore
```

يُرسل التوكن إلى `api.github.com` فقط ولا يُحفظ.

## رموز الخروج

`0` إذا لم يفشل أي فحص، و`1` إذا فشل فحص واحد على الأقل (التحذيرات لا تُحسب)، و`2` إذا احتاج `fix` إلى سؤالك ولا توجد طرفية.

## أمور يجب معرفتها

- الأداة موجّهة لأنظمة Arch. على غيرها تحذّر وتتجاوز ما لا تستطيع فحصه.
- `luac` يفحص صياغة Lua فقط، لا أسماء خيارات Hyprland ولا الإضافات.
- التقارير والسجلات قد تحتوي معلومات خاصة، فاقرأها قبل مشاركتها.
- جُرّبت على عدد قليل من أجهزة Arch. أبلغ عمّا تخطئ فيه.
